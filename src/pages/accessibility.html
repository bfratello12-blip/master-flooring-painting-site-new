Accessibility Statement

We want anyone who lands on this site to be able to use it, whatever device or assistive technology they're on.

Last updated: 2026

Our approach

This website was built with accessibility in mind and we aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA where we reasonably can. Accessibility isn't a one-time task, so we review and improve the site as we make changes to it.

What we've built in

  • Semantic HTML structure with a logical heading order on every page
  • A "skip to main content" link for keyboard and screen reader users
  • Full keyboard navigation, including the menu, dropdowns, accordions and forms
  • Visible focus outlines on every interactive element
  • Descriptive link text and alternative text on meaningful images
  • Form fields with proper labels and clear, specific error messages
  • Color combinations chosen for readable contrast
  • Tap targets sized for comfortable use on phones
  • Reduced motion support for visitors who have that preference enabled
  • Responsive layouts that work at high zoom levels without horizontal scrolling

Ongoing work

Some content on this site — including images that are still being added — may not yet be fully optimized. We're working through it, and any issue that gets reported to us moves to the top of the list.

Third-party content

Some elements on this site link to services we don't control, such as Google, Angi and social media platforms. We can't guarantee the accessibility of content hosted on those platforms.
